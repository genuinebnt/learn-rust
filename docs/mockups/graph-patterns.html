Depth-first search 2 VARIANTS2 / 3

USE IT WHEN
you need to reach, mark or count everything connected to a startthe answer is built on the way back up (subtree sizes, paths, cycle checks)the structure is a maze, a tree, a dependency graph

Shortest to write, and the call stack does the bookkeeping. Depth is limited by the language: about 1000 frames in Python.

def dfs_recursive(graph, start):
    seen = set()

    def visit(u):
        seen.add(u)
        for v in graph[u]:
            if v not in seen:
                visit(v)

    visit(start)
    return seen

The same visit order is not guaranteed (a stack reverses neighbour order), but the reachable set is. Use it for deep graphs and long chains.

def dfs_iterative(graph, start):
    seen = {start}
    stack = [start]
    while stack:
        u = stack.pop()
        for v in graph[u]:
            if v not in seen:
                seen.add(v)  # mark when pushed, so a node is never on the stack twice
                stack.append(v)
    return seen
PITFALLS
  • Mark a node when you first see it, not when you pop it, or one node enters the stack many times.
  • Recursion depth: a 10^5 node chain overflows Python's stack. Switch to the iterative tab.
  • An undirected edge appears twice: skip the parent, or use the visited set.

0-1 BFS EXAMPLES0 / 1

USE IT WHEN
every edge costs 0 or 1 (turn or no turn, flip or keep, free or paid)Dijkstra works but a heap is more machinery than needed
TEMPLATE · PYTHON 
from collections import deque

def zero_one_bfs(graph, src):
    """graph[u] = [(v, w)] with w in {0, 1}."""
    INF = float("inf")
    dist = {u: INF for u in graph}
    dist[src] = 0
    q = deque([src])
    while q:
        u = q.popleft()
        for v, w in graph[u]:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
                # a free edge goes to the front, a paid edge to the back
                q.appendleft(v) if w == 0 else q.append(v)
    return dist
PITFALLS
  • A node can be pushed more than once; the distance check discards the stale entries.
  • Free edges go to the front of the deque. Both to the back is plain BFS and gives wrong answers.
