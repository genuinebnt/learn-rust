Boxrecursive typeFoundationLearning 01
Model an Owned Binary Tree
Prerequisites: Rust structs, enums, and basic ownership; no earlier card.
New idea: Each child is either absent or an exclusively owned heap node: Option<Box<Node>>.
Hint ladder: 1) Put the value directly in the node. 2) Make each child optional. 3) Insert Box between Option and the recursive node so the field has a known size.
Complexity: Allocating n nodes is O(n) time and O(n) heap space; each child edge occupies one pointer-sized option.
Rust angle: Box expresses exclusive parent-to-child ownership and needs neither reference counts nor runtime borrow checks.
Unlocks next: Learning 02’s recursion frame and every owned-tree exercise.
Solution — reveal after attempting (owned node representation)
#[derive(Debug, PartialEq, Eq)]
struct Node {
    value: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

impl Node {
    fn leaf(value: i32) -> Box<Self> {
        Box::new(Self { value, left: None, right: None })
    }
}

fn main() {
    let root = Node {
        value: 8,
        left: Some(Node::leaf(3)),
        right: Some(Node::leaf(10)),
    };
    assert_eq!(root.value, 8);
    assert_eq!(root.left.as_deref().map(|n| n.value), Some(3));
    assert_eq!(root.right.as_deref().map(|n| n.value), Some(10));
}
recursion framebase caseFoundationLearning 02
Recursion Frame: Base Case and Combine Step
Prerequisites: Learning 01 and function-call stack vocabulary.
New idea: One frame handles one optional node: return an identity for None, recursively solve children, then combine their answers with the current value.
Hint ladder: 1) Write the None branch first. 2) Assume both recursive calls are correct. 3) Combine only after both calls return; trace a leaf, then its parent, frame by frame.
Complexity: A full traversal takes O(n) time and O(h) call-stack space for height h.
Rust angle: Recurse over Option<&Node> obtained with as_deref() so the tree remains borrowed, not cloned or consumed.
Unlocks next: Null-safe traversal, size, height, comparison, and tree DP recurrences.
Solution — reveal after attempting (one-frame aggregation)
struct Node {
    value: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

fn sum(node: Option<&Node>) -> i32 {
    match node {
        None => 0,
        Some(node) => {
            node.value + sum(node.left.as_deref()) + sum(node.right.as_deref())
        }
    }
}

fn main() {
    let tree = Node {
        value: 5,
        left: Some(Box::new(Node { value: 2, left: None, right: None })),
        right: Some(Box::new(Node { value: 9, left: None, right: None })),
    };
    assert_eq!(sum(Some(&tree)), 16);
    assert_eq!(sum(None), 0);
}

Write the Null-Safe Traversal Template
Prerequisites: Learning 01–02.
New idea: A traversal should accept the empty tree naturally; pattern matching on Option replaces null checks and unwraps.
Hint ladder: 1) Take Option<&Node>. 2) Do nothing on None. 3) In Some, process exactly once and recurse through both borrowed child links.
Complexity: O(n) time and O(h) stack space.
Rust angle: No unwrap() is needed; exhaustive matching proves both empty and nonempty cases are handled.
Unlocks next: All recursive traversals and structural algorithms.
Solution — reveal after attempting (panic-free visitor)
struct Node {
    value: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

fn visit(node: Option<&Node>, out: &mut Vec<i32>) {
    if let Some(node) = node {
        out.push(node.value);
        visit(node.left.as_deref(), out);
        visit(node.right.as_deref(), out);
    }
}

fn main() {
    let tree = Node {
        value: 1,
        left: Some(Box::new(Node { value: 2, left: None, right: None })),
        right: Some(Box::new(Node { value: 3, left: None, right: None })),
    };
    let mut values = Vec::new();
    visit(Some(&tree), &mut values);
    assert_eq!(values, vec![1, 2, 3]);
    let mut empty = Vec::new();
    visit(None, &mut empty);
    assert!(empty.is_empty());
}
heightsizeFoundationLearning 04
Aggregate Tree Size and Height
Prerequisites: Learning 02–03.
New idea: Return multiple postorder facts from one frame: size adds child sizes; height adds one to the larger child height.
Hint ladder: 1) Define empty height as 0. 2) Ask left and right for both facts. 3) Return (1 + ls + rs, 1 + max(lh, rh)).
Complexity: O(n) time and O(h) stack space in one traversal.
Rust angle: A tuple keeps related aggregates in one borrowed walk and avoids repeated traversal.
Unlocks next: Balance, diameter, complete-tree counting, and tree DP.
Solution — reveal after attempting (postorder tuple)
struct Node {
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

fn stats(node: Option<&Node>) -> (usize, usize) {
    match node {
        None => (0, 0),
        Some(node) => {
            let (ls, lh) = stats(node.left.as_deref());
            let (rs, rh) = stats(node.right.as_deref());
            (1 + ls + rs, 1 + lh.max(rh))
        }
    }
}

fn leaf() -> Box<Node> {
    Box::new(Node { left: None, right: None })
}

fn main() {
    let tree = Node {
        left: Some(leaf()),
        right: Some(Box::new(Node { left: Some(leaf()), right: None })),
    };
    assert_eq!(stats(Some(&tree)), (4, 3));
    assert_eq!(stats(None), (0, 0));
}
BoxRcRefCellFoundationLearning 05
Choose Box or Rc<RefCell<_>>
Prerequisites: Learning 01–04; shared versus exclusive ownership.
New idea: Representation follows topology: Box for one owning parent; Rc for multiple handles; add RefCell only for shared mutation.
Hint ladder: 1) Ask whether a node has one owner. 2) Ask whether aliases must mutate it. 3) Prefer the least powerful type that satisfies both answers.
Complexity: Both traverse in O(n); Rc adds reference-count operations and RefCell adds runtime borrow checks.
Rust angle: RefCell moves borrow enforcement to runtime and can panic on overlapping mutable/shared borrows; it is not a default tree pointer.
Unlocks next: Shared node handles, parent links, identity-based algorithms, and persistent alternatives.
Solution — reveal after attempting (representation contrast)
use std::cell::RefCell;
use std::rc::Rc;

struct Owned {
    value: i32,
    child: Option<Box<Owned>>,
}

struct Shared {
    value: i32,
    child: Option<Rc<RefCell<Shared>>>,
}

fn main() {
    let owned = Owned {
        value: 1,
        child: Some(Box::new(Owned { value: 2, child: None })),
    };
    assert_eq!(owned.child.as_deref().map(|n| n.value), Some(2));
    assert!(owned.child.as_deref().unwrap().child.is_none());

    let child = Rc::new(RefCell::new(Shared { value: 4, child: None }));
    let root = Shared { value: 3, child: Some(Rc::clone(&child)) };
    child.borrow_mut().value = 9;
    assert_eq!(root.value, 3);
    assert_eq!(root.child.as_ref().unwrap().borrow().value, 9);
    assert_eq!(Rc::strong_count(&child), 2);
}

Build and Mutate a Shared Tree Safely
Prerequisites: Learning 05 and the Rust Book’s Rc/RefCell chapters.
New idea: Clone handles, not nodes; keep each borrow() or borrow_mut() scope short before recursion or a second borrow.
Hint ladder: 1) Alias a child with Rc::clone. 2) Mutate through borrow_mut(). 3) Drop that guard before reading through another handle; use Rc::ptr_eq for identity.
Complexity: Handle cloning and direct mutation are O(1); the nodes remain O(n) space.
Rust angle: Strong parent and child links can create cycles and leaks; use Weak for non-owning back edges.
Unlocks next: Identity-sensitive trees and a clear reason to prefer indexed arenas for advanced query algorithms.
Solution — reveal after attempting (shared handles)
use std::cell::RefCell;
use std::rc::Rc;

type Link = Option<Rc<RefCell<Node>>>;

struct Node {
    value: i32,
    left: Link,
    right: Link,
}

fn node(value: i32) -> Rc<RefCell<Node>> {
    Rc::new(RefCell::new(Node { value, left: None, right: None }))
}

fn main() {
    let root = node(1);
    let child = node(2);
    root.borrow_mut().left = Some(Rc::clone(&child));
    child.borrow_mut().value = 7;

    let from_root = root.borrow().left.as_ref().unwrap().clone();
    assert!(Rc::ptr_eq(&from_root, &child));
    assert_eq!(from_root.borrow().value, 7);

}
iterative DFSstackFoundationLearning 07
Replace Recursion with an Explicit DFS Stack
Prerequisites: Learning 03 and preorder’s root-left-right target order.
New idea: An explicit LIFO stack stores the work that recursive frames would have remembered.
Hint ladder: 1) Push the root if present. 2) Pop, visit, then schedule children. 3) Push right before left so left is popped first; test a skewed tree and empty input.
Complexity: O(n) time and O(h) stack space on a depth-first walk, up to O(n) in the worst shape.
Rust angle: Store borrowed &Node handles when only reading; store owned boxes only if consuming the tree.
Unlocks next: Iterative preorder, stateful inorder/postorder, and stack-safe traversal of deep trees.
Solution sketch — reveal after attempting
Initialize Vec<&Node> with root.as_deref() when present. While the stack is nonempty, pop and record the node, then push right.as_deref() followed by left.as_deref(). Assert root-left-right order, an empty tree, and a one-sided chain.
BFSVecDequeFoundationLearning 08
Traverse Breadth-First with a Queue
Prerequisites: Learning 03 and FIFO queue behavior.
New idea: BFS visits by nondecreasing depth; the queue holds discovered nodes whose children are not yet scheduled.
Hint ladder: 1) Use VecDeque, not Vec::remove(0). 2) Pop front and push children back. 3) For levels, snapshot queue.len() before processing that layer.
Complexity: O(n) time and O(w) queue space for maximum width w.
Rust angle: Queue entries can be immutable references tied to the tree borrow; no Rc is required for read-only BFS.
Unlocks next: Learning 12 level grouping, vertical traversal, and complete-tree/heap reasoning.
Solution sketch — reveal after attempting
Create VecDeque<&Node>. Push the root reference, repeatedly pop_front, record its value, and push_back each existing child. Preserve left-before-right enqueue order and test empty, singleton, balanced, and skewed trees.

    value: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,

fn preorder(node: Option<&Node>, out: &mut Vec<i32>) {

Return BFS Values Grouped by Level
Prerequisites: Learning 08 and VecDeque.
New idea: At loop start, queue length equals the number of nodes in the current level; process exactly that many before emitting the level.
Hint ladder: 1) Snapshot length before popping. 2) Use a fresh vector per level. 3) Enqueued children belong to the next level, so do not extend the current loop bound.
Complexity: O(n) time and O(w) queue space, plus O(n) returned output.
Rust angle: VecDeque<&Node> borrows the immutable tree and gives O(1) amortized operations at both ends.
Unlocks next: Vertical traversal, width reasoning, and implicit complete-tree storage.
Solution — reveal after attempting (level-sized BFS)
use std::collections::VecDeque;

struct Node {
    value: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

fn levels(root: Option<&Node>) -> Vec<Vec<i32>> {
    let mut out = Vec::new();
    let mut queue = VecDeque::new();
    if let Some(root) = root { queue.push_back(root); }
    while !queue.is_empty() {
        let mut level = Vec::new();
        for _ in 0..queue.len() {
            let node = queue.pop_front().unwrap();
            level.push(node.value);
            if let Some(left) = node.left.as_deref() { queue.push_back(left); }
            if let Some(right) = node.right.as_deref() { queue.push_back(right); }
        }
        out.push(level);
    }
    out
}

fn main() {
    let tree = Node {
        value: 1,
        left: Some(Box::new(Node { value: 2, left: None, right: None })),
        right: Some(Box::new(Node { value: 3, left: None, right: None })),
    };
    assert_eq!(levels(Some(&tree)), vec![vec![1], vec![2, 3]]);
    assert!(levels(None).is_empty());
}

Prerequisites: Learning 03 and parallel recursion.
New idea: Two subtrees mirror when roots match and outer children mirror each other while inner children mirror each other.
Hint ladder: 1) Handle all four presence combinations. 2) Compare values. 3) Pair left.left with right.right and left.right with right.left.
Complexity: O(n) time and O(h) stack space.
Rust angle: Match pairs of borrowed options; exhaustive matching avoids dereferencing absent children.
Unlocks next: Same-tree comparison and paired structural recursion.
Solution — reveal after attempting (cross-child comparison)
struct Node {
    value: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

fn mirror(a: Option<&Node>, b: Option<&Node>) -> bool {
    match (a, b) {
        (None, None) => true,
        (Some(a), Some(b)) => {
            a.value == b.value
                && mirror(a.left.as_deref(), b.right.as_deref())
                && mirror(a.right.as_deref(), b.left.as_deref())
        }
        _ => false,
    }
}

fn leaf(value: i32) -> Box<Node> {
    Box::new(Node { value, left: None, right: None })
}

fn main() {
    let tree = Node { value: 1, left: Some(leaf(2)), right: Some(leaf(2)) };
    assert!(mirror(tree.left.as_deref(), tree.right.as_deref()));
    let other = Node { value: 1, left: Some(leaf(2)), right: Some(leaf(3)) };
    assert!(!mirror(other.left.as_deref(), other.right.as_deref()));
}

struct Node {
    value: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

fn same(a: Option<&Node>, b: Option<&Node>) -> bool {
    match (a, b) {
        (None, None) => true,
        (Some(a), Some(b)) => {
            a.value == b.value
                && same(a.left.as_deref(), b.left.as_deref())
                && same(a.right.as_deref(), b.right.as_deref())
        }
        _ => false,
    }
}

fn leaf(value: i32) -> Box<Node> {
    Box::new(Node { value, left: None, right: None })
}

fn main() {
    let a = Node { value: 1, left: Some(leaf(2)), right: None };
    let b = Node { value: 1, left: Some(leaf(2)), right: None };
    let c = Node { value: 1, left: None, right: Some(leaf(2)) };
    assert!(same(Some(&a), Some(&b)));
    assert!(!same(Some(&a), Some(&c)));
    assert!(same(None, None));
}

BST searchbranch pruningMediumLearning 19
Search a Binary Search Tree
Prerequisites: Learning 10 and the invariant “left keys < node < right keys.”
New idea: Compare once per level and discard one entire subtree; this is binary search over a tree-defined predicate path.
Hint ladder: 1) Empty means absent. 2) Equality returns success. 3) Smaller targets recurse left and larger targets recurse right; never search both.
Complexity: O(h) time and O(h) recursive stack, O(1) space iteratively; h is O(log n) only when balanced.
Rust angle: Return Option<&Node> to expose a borrowed match whose lifetime is tied to the tree.
Unlocks next: Insertion, deletion, range pruning, BST LCA, and treaps.
Solution — reveal after attempting (ordered descent)
struct Node {
    key: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

fn search(mut node: Option<&Node>, target: i32) -> Option<&Node> {
    while let Some(current) = node {
        if target == current.key { return Some(current); }
        node = if target < current.key {
            current.left.as_deref()
        } else {
            current.right.as_deref()
        };
    }
    None
}

fn main() {
    let tree = Node {
        key: 8,
        left: Some(Box::new(Node { key: 3, left: None, right: None })),
        right: Some(Box::new(Node { key: 10, left: None, right: None })),
    };
    assert_eq!(search(Some(&tree), 3).map(|n| n.key), Some(3));
    assert!(search(Some(&tree), 7).is_none());
    assert!(search(None, 1).is_none());
}

struct Node {
    key: i32,
    left: Option<Box<Node>>,
    right: Option<Box<Node>>,
}

fn insert(link: &mut Option<Box<Node>>, key: i32) -> bool {
    match link {
        None => {
            *link = Some(Box::new(Node { key, left: None, right: None }));

struct Lca {
    up: Vec<Vec<usize>>,
    depth: Vec<usize>,
}

impl Lca {
    fn new(graph: &[Vec<usize>], root: usize) -> Self {
        let n = graph.len();
        let log = (usize::BITS - n.max(1).leading_zeros()) as usize;
        let mut up = vec![vec![root; n]; log.max(1)];
        let mut depth = vec![0; n];
        let mut stack = vec![(root, root)];
        while let Some((v, parent)) = stack.pop() {
            up[0][v] = parent;
            for &to in &graph[v] {
                if to != parent {
                    depth[to] = depth[v] + 1;
                    stack.push((to, v));
                }
            }
        }
        for j in 1..up.len() {
            for v in 0..n { up[j][v] = up[j - 1][up[j - 1][v]]; }
        }
        Self { up, depth }
    }

    fn lca(&self, mut a: usize, mut b: usize) -> usize {
        if self.depth[a] < self.depth[b] { std::mem::swap(&mut a, &mut b); }
        let diff = self.depth[a] - self.depth[b];
        for j in 0..self.up.len() {
            if diff & (1 << j) != 0 { a = self.up[j][a]; }
        }
        if a == b { return a; }
        for j in (0..self.up.len()).rev() {
            if self.up[j][a] != self.up[j][b] {
                a = self.up[j][a];
                b = self.up[j][b];
            }
        }
        self.up[0][a]
    }
}

    let lca = Lca::new(&graph, 0);
    assert_eq!(lca.lca(3, 4), 1);
    assert_eq!(lca.lca(2, 4), 0);
    assert_eq!(lca.lca(1, 4), 1);

struct Fenwick {
    bit: Vec<i64>,
}

impl Fenwick {
    fn new(n: usize) -> Self { Self { bit: vec![0; n + 1] } }

    fn add(&mut self, index: usize, delta: i64) {
        let mut i = index + 1;
        while i < self.bit.len() {
            self.bit[i] += delta;
            i += i & i.wrapping_neg();
        }
    }

    fn prefix(&self, end: usize) -> i64 {
        let mut i = end;
        let mut sum = 0;
        while i > 0 {
            sum += self.bit[i];
            i -= i & i.wrapping_neg();
        }
        sum
    }

    fn range(&self, left: usize, right: usize) -> i64 {
        self.prefix(right) - self.prefix(left)
    }
}

    for (i, value) in [2, 1, 4, 3, 5].into_iter().enumerate() { bit.add(i, value); }
    assert_eq!(bit.prefix(3), 7);
    assert_eq!(bit.range(1, 4), 8);
    bit.add(2, 6);
    assert_eq!(bit.range(2, 5), 18);

struct SegTree {
    n: usize,
    tree: Vec<i64>,
}

impl SegTree {
    fn from(values: &[i64]) -> Self {
        let n = values.len();
        let mut tree = vec![0; 2 * n.max(1)];
        if n > 0 {
            tree[n..2 * n].copy_from_slice(values);
            for i in (1..n).rev() { tree[i] = tree[2 * i] + tree[2 * i + 1]; }
        }
        Self { n, tree }
    }

    fn set(&mut self, index: usize, value: i64) {
        let mut i = index + self.n;
        self.tree[i] = value;
        while i > 1 {
            i /= 2;
            self.tree[i] = self.tree[2 * i] + self.tree[2 * i + 1];
        }
    }

    fn query(&self, mut left: usize, mut right: usize) -> i64 {
        left += self.n;
        right += self.n;
        let mut sum = 0;
        while left < right {
            if left % 2 == 1 { sum += self.tree[left]; left += 1; }
            if right % 2 == 1 { right -= 1; sum += self.tree[right]; }
            left /= 2;
            right /= 2;
        }
        sum
    }
}

fn main() {
    let mut seg = SegTree::from(&[2, 1, 4, 3, 5]);
    assert_eq!(seg.query(1, 4), 8);
    assert_eq!(seg.query(0, 5), 15);
    seg.set(2, 10);
    assert_eq!(seg.query(1, 4), 14);
    assert_eq!(SegTree::from(&[]).query(0, 0), 0);
}

#[derive(Default)]
struct MinHeap {
    data: Vec<i32>,
}

impl MinHeap {
    fn push(&mut self, value: i32) {
        self.data.push(value);
        let mut i = self.data.len() - 1;
        while i > 0 {
            let parent = (i - 1) / 2;
            if self.data[parent] <= self.data[i] { break; }
            self.data.swap(parent, i);
            i = parent;
        }
    }

    fn pop(&mut self) -> Option<i32> {
        let last = self.data.pop()?;
        if self.data.is_empty() { return Some(last); }
        let result = std::mem::replace(&mut self.data[0], last);
        let mut i = 0;
        loop {
            let left = 2 * i + 1;
            if left >= self.data.len() { break; }
            let right = left + 1;
            let child = if right < self.data.len() && self.data[right] < self.data[left] {
                right
            } else { left };
            if self.data[i] <= self.data[child] { break; }
            self.data.swap(i, child);
            i = child;
        }
        Some(result)
    }
}

fn main() {
    let mut heap = MinHeap::default();
    for value in [5, 1, 4, 1, 3] { heap.push(value); }
    let mut out = Vec::new();
    while let Some(value) = heap.pop() { out.push(value); }
    assert_eq!(out, vec![1, 1, 3, 4, 5]);
    assert_eq!(heap.pop(), None);
}

struct LazySeg {
    n: usize,
    sum: Vec<i64>,
    lazy: Vec<i64>,
}

impl LazySeg {
    fn new(values: &[i64]) -> Self {
        let n = values.len();
        let mut seg = Self { n, sum: vec![0; 4 * n.max(1)], lazy: vec![0; 4 * n.max(1)] };
        if n > 0 { seg.build(1, 0, n, values); }
        seg
    }
    fn build(&mut self, p: usize, l: usize, r: usize, a: &[i64]) {
        if r - l == 1 { self.sum[p] = a[l]; return; }
        let m = (l + r) / 2;
        self.build(2 * p, l, m, a);
        self.build(2 * p + 1, m, r, a);
        self.sum[p] = self.sum[2 * p] + self.sum[2 * p + 1];
    }
    fn apply(&mut self, p: usize, l: usize, r: usize, delta: i64) {
        self.sum[p] += delta * (r - l) as i64;
        self.lazy[p] += delta;
    }
    fn push(&mut self, p: usize, l: usize, r: usize) {
        if self.lazy[p] == 0 || r - l == 1 { return; }
        let m = (l + r) / 2;
        let delta = std::mem::take(&mut self.lazy[p]);
        self.apply(2 * p, l, m, delta);
        self.apply(2 * p + 1, m, r, delta);
    }
    fn add_rec(&mut self, p: usize, l: usize, r: usize, ql: usize, qr: usize, d: i64) {
        if qr <= l || r <= ql { return; }
        if ql <= l && r <= qr { self.apply(p, l, r, d); return; }
        self.push(p, l, r);
        let m = (l + r) / 2;
        self.add_rec(2 * p, l, m, ql, qr, d);
        self.add_rec(2 * p + 1, m, r, ql, qr, d);
        self.sum[p] = self.sum[2 * p] + self.sum[2 * p + 1];
    }
    fn query_rec(&mut self, p: usize, l: usize, r: usize, ql: usize, qr: usize) -> i64 {
        if qr <= l || r <= ql { return 0; }
        if ql <= l && r <= qr { return self.sum[p]; }
        self.push(p, l, r);
        let m = (l + r) / 2;
        self.query_rec(2 * p, l, m, ql, qr)
            + self.query_rec(2 * p + 1, m, r, ql, qr)
    }
    fn add(&mut self, l: usize, r: usize, d: i64) {
        if self.n > 0 { self.add_rec(1, 0, self.n, l, r, d); }
    }
    fn query(&mut self, l: usize, r: usize) -> i64 {
        if self.n == 0 { 0 } else { self.query_rec(1, 0, self.n, l, r) }
    }
}

fn main() {
    let mut seg = LazySeg::new(&[1, 2, 3, 4, 5]);
    seg.add(1, 4, 10);
    assert_eq!(seg.query(0, 5), 45);
    assert_eq!(seg.query(1, 3), 25);
    seg.add(2, 5, -2);
    assert_eq!(seg.query(2, 5), 26);
    assert_eq!(LazySeg::new(&[]).query(0, 0), 0);
}

struct Hld {
    parent: Vec<usize>, depth: Vec<usize>, head: Vec<usize>, pos: Vec<usize>,
    bit: Vec<i64>,
}

impl Hld {
    fn new(graph: &[Vec<usize>], values: &[i64], root: usize) -> Self {
        fn sizes(v: usize, p: usize, g: &[Vec<usize>], parent: &mut [usize],
                 depth: &mut [usize], size: &mut [usize], heavy: &mut [usize]) {
            parent[v] = p; size[v] = 1;
            let mut best = 0;
            for &to in &g[v] {
                if to == p { continue; }
                depth[to] = depth[v] + 1;
                sizes(to, v, g, parent, depth, size, heavy);
                size[v] += size[to];
                if size[to] > best { best = size[to]; heavy[v] = to; }
            }
        }
        fn decompose(v: usize, p: usize, chain: usize, g: &[Vec<usize>], heavy: &[usize],
                     head: &mut [usize], pos: &mut [usize], timer: &mut usize) {
            head[v] = chain; pos[v] = *timer; *timer += 1;
            if heavy[v] != usize::MAX {
                decompose(heavy[v], v, chain, g, heavy, head, pos, timer);
            }
            for &to in &g[v] {
                if to != p && to != heavy[v] {
                    decompose(to, v, to, g, heavy, head, pos, timer);
                }
            }
        }
        let n = graph.len();
        let mut parent = vec![root; n]; let mut depth = vec![0; n];
        let mut size = vec![0; n]; let mut heavy = vec![usize::MAX; n];
        sizes(root, root, graph, &mut parent, &mut depth, &mut size, &mut heavy);
        let mut head = vec![0; n]; let mut pos = vec![0; n]; let mut timer = 0;
        decompose(root, root, root, graph, &heavy, &mut head, &mut pos, &mut timer);
        let mut hld = Self { parent, depth, head, pos, bit: vec![0; n + 1] };
        for v in 0..n { hld.add(v, values[v]); }
        hld
    }
    fn add(&mut self, node: usize, delta: i64) {
        let mut i = self.pos[node] + 1;
        while i < self.bit.len() { self.bit[i] += delta; i += i & i.wrapping_neg(); }
    }
    fn prefix(&self, mut i: usize) -> i64 {
        let mut sum = 0;
        while i > 0 { sum += self.bit[i]; i -= i & i.wrapping_neg(); }
        sum
    }
    fn segment(&self, l: usize, r: usize) -> i64 { self.prefix(r) - self.prefix(l) }
    fn path_sum(&self, mut a: usize, mut b: usize) -> i64 {
        let mut sum = 0;
        while self.head[a] != self.head[b] {
            if self.depth[self.head[a]] < self.depth[self.head[b]] {
                std::mem::swap(&mut a, &mut b);
            }
            sum += self.segment(self.pos[self.head[a]], self.pos[a] + 1);
            a = self.parent[self.head[a]];
        }
        let (l, r) = if self.pos[a] <= self.pos[b] { (a, b) } else { (b, a) };
        sum + self.segment(self.pos[l], self.pos[r] + 1)
    }
}

fn main() {
    let graph = vec![vec![1, 2], vec![0, 3, 4], vec![0], vec![1], vec![1]];
    let mut hld = Hld::new(&graph, &[1, 2, 3, 4, 5], 0);
    assert_eq!(hld.path_sum(3, 2), 10);
    assert_eq!(hld.path_sum(3, 4), 11);
    hld.add(1, 10);
    assert_eq!(hld.path_sum(3, 4), 21);
}
