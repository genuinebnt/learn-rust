Rust Learning Platform

A complete curriculum spanning beginner fundamentals, the standard library, ownership and type-system internals, unsafe Rust, async, systems programming, compilers, databases, distributed systems, backend engineering, performance, and production Rust.

The core learning model

Every important Rust concept should be taught through progressively deeper layers rather than stopping after explaining the API.

01
Use it Learn the normal API and solve practical problems.
02
Understand it Learn memory, ownership, invariants, trade-offs and internals.
03
Implement it Build a simplified version from scratch.
04
Read the real implementation Explore std, Tokio, rustc and production crates.

Learning levels

The platform should behave more like a skill graph than a linear video course. Learners can go deep into individual areas while prerequisites remain visible.

Foundation
Syntax, ownership, borrowing, collections, errors and Cargo.
Intermediate
Traits, generics, lifetimes, iterators, modules, testing and concurrency.
Advanced
Unsafe, async internals, macros, memory layout, FFI and performance.
Expert
rustc, std internals, OS, databases, distributed systems and language design.

What makes the platform different

1. API-first learning

Every important Rust API is something learners can use, inspect and eventually recreate.

2. Source-code learning

Advanced lessons point learners directly at real implementations in std, Tokio, rustc and major crates.

3. Invariant-driven unsafe Rust

Unsafe exercises are not just pointer puzzles. Learners must state the safety invariants before writing unsafe code.

4. Progressive implementation

Build simplified versions first, then compare them against production implementations and understand why the real design differs.

5. Skill graph

Prerequisites, projects and assessments determine what the learner should study next instead of forcing one rigid course sequence.

6. From Rust user to Rust engineer

The final destination is not merely writing idiomatic Rust. It is being able to reason about memory, concurrency, compilers, runtimes, databases and large Rust codebases.
