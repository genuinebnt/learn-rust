def subsets(nums):
    out, path = [], []

    def go(i):
        if i == len(nums):
            out.append(path[:])  # copy: the list keeps changing
            return
        path.append(nums[i])     # take it
        go(i + 1)
        path.pop()               # undo
        go(i + 1)               # skip it

    go(0)
    return out
TRAPS
  • Copy the path when you record it.
  • Pop after every recursive call.
  • 2ⁿ answers: the output size is the lower bound on the work.
