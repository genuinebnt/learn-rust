Network delay time

A network has n nodes labelled 1 to n and a list of directed, weighted edges times[i] = (u, v, w): a signal takes w ms to travel from u to v.

A signal is sent from node k. Return how long it takes every node to receive it, or None if some node can't be reached.

pub fn network_delay( times: &[(usize, usize, u32)], n: usize, k: usize, ) -> Option<u32>
EXAMPLE
times[(2,1,1), (2,3,1), (3,4,1)] n, k4, 2 returnsSome(2)
CONSTRAINTS
1 ≤ n ≤ 100
1 ≤ times.len() ≤ 6000
0 ≤ w ≤ 100 · no self-loops
WHAT THIS TEACHES
BinaryHeap is a max-heap; Reverse flips it.
Lazy deletion instead of decrease-key.
Sentinels vs Option at the boundary.
